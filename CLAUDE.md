# Журнал производства

Веб-приложение (PWA) для планшета: смены, поломки, ремонт, склад, мануалы.
Чистый HTML/CSS/JS без сборки. Публикуется на GitHub Pages из ветки `main`.

## Офлайн-кэш (sw.js)

- Изменил любой файл приложения — поднять `VERSION` в `sw.js`, иначе установленное
  приложение на планшете будет показывать старую копию.
- Добавил `manuals/kb-*.js` (или другой файл оболочки) — добавить его в список `SHELL` в `sw.js`.
- Данные приложения service worker не кэширует: они в localStorage (позже OneDrive).

## Обработка новых мануалов

Запрос пользователя вида «обработай новые мануалы» означает:

1. Найти новые файлы в `мануалы-исходники/<Производитель>/` — те, на которые ещё
   нет поля `file` ни в одном `manuals/kb-*.js`. Папка в `.gitignore`: исходники
   не публикуются (репозиторий открытый).
2. Если файл лежит не в папке производителя или назван невнятно — определить
   производителя и модель по первым страницам и переложить в
   `мануалы-исходники/<Производитель>/<Производитель> <Модель>, <что это> — <тип документа> (<язык>).pdf`.
3. Извлечь текст: `pdftotext -enc UTF-8 -layout -fixed 3 -f N -l M файл.pdf out.txt`
   (`-fixed 3` сохраняет колонки таблиц; без него таблицы перемешиваются).
   Найти разделы с кодами ошибок, предупреждениями и таблицами неисправностей.
4. Создать `manuals/kb-<производитель>.js` (или дополнить существующий) по образцу
   соседних файлов: `KB_ADD({ id, maker, model, title, kind, lang, file, note, entries })`.
   Каждая запись: `code` (как на дисплее; перечисление через запятую или диапазон
   `E50…E59`), `kind` (`alarm` / `warning` / `symptom`), `title`, `causes[]`,
   `steps[]`, `page` — **страница PDF** (проверить: `pdftotext -f page -l page`),
   `kw` — дополнительные слова для поиска. Всё — на русском, переводить, если нужно.
   Сервоприводы семейства Yaskawa Sigma (и копии вроде HCFA) с вращающимися двигателями
   берут общие записи из `kb-sigma-common.js`: `entries: sigmaEntries({ 'A.020': стр., ... })`.
5. Подключить файл `<script>` в `index.html` рядом с остальными `manuals/kb-*.js`,
   добавить его в `SHELL` в `sw.js` и поднять `VERSION`.
6. Проверить в headless Chrome, что база загружается и поиск находит новые коды;
   показать пользователю количество записей и пару примеров.

Если пользователь присылает только названия оборудования — найти мануалы в сети
(официальные сайты, русские дистрибьюторы), скачать curl'ом в папку производителя и
обработать по шагам выше. Сканы без текстового слоя не обрабатываются (нет OCR).

## Совет Claude в базе знаний

Запись `entries` в `manuals/kb-*.js` может иметь поле `advice: ['…', '…']` — практические советы
от Claude. Они показываются отдельным блоком «Совет Claude · не из мануала» под текстом мануала.

- Совет — только по общим знаниям и смыслу записи, не подаётся как цитата мануала. Факты из мануала
  остаются в `causes` и `steps` со ссылкой на страницу.
- Опасное (высокое напряжение, остаточный заряд в приводах, гидравлика под давлением) своими советами
  не расширять: максимум «обесточить, подождать разряда, вызвать электрика».
- Не придумывать параметры, номиналы и значения, которых нет в мануале.
- Пилот: `kb-shini.js` (6 записей). Остальные базы — по запросу.
